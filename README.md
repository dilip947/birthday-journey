# Birthday Journey

A cinematic, interactive birthday story built with Next.js, TypeScript, Tailwind CSS, Framer Motion, and Lenis.

## Start locally

```bash
npm install
npm run dev
```

Then open http://localhost:3000

## Project approach

- `app/` — routes and global styling
- `components/` — reusable visual and animation components
- `data/` — relationship story content
- `public/` — photos, video, audio, and textures
- `lib/` — animation and utility helpers
- `hooks/` — reusable React hooks
- `types/` — TypeScript models
